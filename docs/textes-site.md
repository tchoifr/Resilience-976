## Actions recommandees

### action_family_plan
- Titre : Préparer un plan familial simple
- Pourquoi : Un plan connu de tous réduit les hésitations quand les communications sont difficiles.
- Instructions :
  - Désigner un point de regroupement facile à mémoriser.
  - Partager les rôles simples entre adultes et aidants.
  - Vérifier que chaque personne sait quoi faire en cas de consigne officielle.

### action_contacts
- Titre : Noter les contacts essentiels hors téléphone
- Pourquoi : Une batterie vide ou un téléphone perdu peut rendre les numéros inaccessibles.
- Instructions :
  - Lister les contacts proches et services utiles sur un support papier.
  - Conserver une copie dans le kit.
  - Mettre la liste à jour à chaque changement important.

### action_check_neighbors
- Titre : Identifier un relais de proximité
- Pourquoi : La solidarité de voisinage aide à repérer rapidement les personnes isolées.
- Instructions :
  - Choisir une personne de confiance à proximité.
  - Partager uniquement les informations utiles et consenties.
  - Prévoir un mode de vérification simple après un événement.

### action_repli_zone
- Titre : Identifier une zone de repli dans le logement
- Pourquoi : Une zone connue à l’avance évite de chercher une solution dans l’urgence.
- Instructions :
  - Identifier une zone plus sûre selon les consignes officielles.
  - Expliquer ce choix au foyer.
  - Ne pas utiliser cette action comme consigne d’évacuation.

### action_secure_openings
- Titre : Prévoir la sécurisation des ouvertures
- Pourquoi : Des ouvertures préparées peuvent limiter les dommages et les dangers.
- Instructions :
  - Vérifier portes, fenêtres et protections existantes.
  - Préparer les gestes faisables rapidement.
  - Demander un avis professionnel pour les travaux ou risques importants.

### action_clear_exterior
- Titre : Ranger les objets extérieurs mobiles
- Pourquoi : Les objets mobiles peuvent devenir dangereux par vent fort.
- Instructions :
  - Lister les objets à rentrer ou attacher.
  - Prévoir où les stocker.
  - Agir avant que les conditions ne se dégradent.

### action_water_reserve
- Titre : Préparer une réserve d’eau
- Pourquoi : Une coupure d’eau peut survenir après un événement majeur.
- Instructions :
  - Vérifier la recommandation officielle en vigueur.
  - Adapter la réserve à la composition du foyer.
  - Contrôler régulièrement la rotation des réserves.

### action_food_reserve
- Titre : Préparer une réserve alimentaire simple
- Pourquoi : Des aliments adaptés au foyer aident à tenir pendant une perturbation temporaire.
- Instructions :
  - Choisir des aliments connus du foyer.
  - Éviter les produits difficiles à préparer sans énergie.
  - Planifier une rotation régulière.

### action_light
- Titre : Préparer un éclairage de secours
- Pourquoi : Un éclairage autonome facilite les gestes essentiels en cas de coupure.
- Instructions :
  - Regrouper lampes et piles ou batteries.
  - Vérifier leur fonctionnement.
  - Éviter de dépendre uniquement du téléphone.

### action_radio
- Titre : Prévoir un moyen d’information officiel
- Pourquoi : Les informations officielles restent prioritaires pendant une crise.
- Instructions :
  - Identifier les canaux officiels locaux.
  - Prévoir un moyen qui ne dépend pas uniquement d’internet.
  - Tester le moyen choisi avant la saison à risque.

### action_power_bank
- Titre : Charger et vérifier les batteries de secours
- Pourquoi : Une réserve d’énergie prolonge l’accès aux informations et contacts utiles.
- Instructions :
  - Charger les batteries externes.
  - Ranger les câbles compatibles.
  - Prévoir une vérification régulière.

### action_official_sources
- Titre : Enregistrer les sources officielles
- Pourquoi : Les consignes peuvent évoluer ; les sources officielles doivent rester la référence.
- Instructions :
  - Identifier les sites et canaux locaux fiables.
  - Les conserver dans le téléphone et sur support papier si utile.
  - Vérifier les informations avant de les partager.

### action_docs
- Titre : Protéger les copies utiles des documents
- Pourquoi : Des copies accessibles peuvent faciliter les démarches après un événement.
- Instructions :
  - Identifier les documents utiles sans les saisir dans l’application.
  - Conserver des copies protégées de l’eau.
  - Vérifier les droits et la confidentialité des copies.

### action_medicine_plan
- Titre : Anticiper les traitements essentiels hors application
- Pourquoi : Certains besoins de santé ne doivent pas être improvisés pendant une crise.
- Instructions :

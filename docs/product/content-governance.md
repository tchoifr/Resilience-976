# Gouvernance des contenus

## Statuts

- `draft`: brouillon non relu.
- `to_validate`: pret a etre relu par un referent metier.
- `validated`: valide pour publication.

## Responsabilites

| Objet            | Responsable                | Validation                        |
| ---------------- | -------------------------- | --------------------------------- |
| Questions        | Referent risques + porteur | Formulation, poids, criticite     |
| Actions          | Referent risques           | Exactitude, faisabilite, sources  |
| Kit              | Referent risques           | Elements et quantites             |
| Sources          | Responsable editorial      | Organisme, date, URL, droits      |
| Mentions legales | Porteur                    | Responsabilite et confidentialite |

## Regles

- Ne jamais inventer de quantite sensible.
- Associer chaque recommandation sensible a une source.
- Conserver la date de revision.
- Ne pas melanger les resultats issus de versions differentes du questionnaire.
- Modifier le numero de version si le bareme change.

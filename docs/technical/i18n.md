# Internationalisation

## Principe

Les textes visibles par l'utilisateur sont stockes dans des fichiers dedies.

Textes d'interface, SEO, PDF et libelles partages :

- `src/shared/i18n/locales/fr.ts`

Contenus metier affiches dans l'application :

- `src/data/actions.json`
- `src/data/kit.json`
- `src/data/questions.json`
- `src/data/resources.json`
- `src/data/sources.json`
- `src/data/videos.json`

Le service i18n qui lit les textes de traduction est :

- `src/shared/i18n/i18n.service.ts`

Les composants, vues, services et types ne doivent pas contenir de texte visible en dur. Ils doivent
utiliser `t(...)`, les helpers i18n, ou les contenus charges depuis les fichiers JSON ci-dessus.

## Ajouter une langue

1. Creer un dictionnaire avec la meme structure que `frMessages`.
2. Enregistrer ce dictionnaire avec `registerLocale({ code, label, messages })`.
3. Ajouter les contenus metier traduits si la langue doit aussi changer les questions, actions,
   kits, ressources, sources et videos.

Le service garde un repli francais: une cle manquante dans une langue affichera le texte francais
equivalent au lieu de casser l'interface.

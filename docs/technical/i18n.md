# Internationalisation

## Principe

Les textes fixes de l'interface, du SEO et des PDF sont centralises dans :

- `src/shared/i18n/locales/fr.ts`
- `src/shared/i18n/i18n.service.ts`

Les contenus metier visibles du diagnostic, des recommandations, du kit et des ressources restent
dans les fichiers JSON de `src/data`. Ils peuvent etre dupliques par langue lors d'une prochaine
etape de localisation complete.

## Ajouter une langue

1. Creer un dictionnaire avec la meme structure que `frMessages`.
2. Enregistrer ce dictionnaire avec `registerLocale({ code, label, messages })`.
3. Ajouter les contenus metier traduits si la langue doit aussi changer les questions, actions,
   kits, ressources et sources.

Le service garde un repli francais: une cle manquante dans une langue affichera le texte francais
equivalent au lieu de casser l'interface.

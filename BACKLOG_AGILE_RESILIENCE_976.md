## Cadre Produit

Resilience 976 est une application web publique, mobile-first, sans compte et sans base de donnees. Elle permet a un foyer de realiser un diagnostic de preparation aux catastrophes naturelles, d'obtenir un score, des recommandations, une checklist, un kit d'urgence personnalise et un PDF recapitulatif. Les reponses restent dans le navigateur via `localStorage`; les contenus sont des fichiers JSON versionnes.

## Definition of Ready

- Le besoin utilisateur est formule sous forme de user story.
- Le domaine, l'epic, la priorite et la valeur metier sont identifies.
- Les criteres d'acceptation sont testables.
- Les dependances fonctionnelles ou techniques sont connues.
- Les contenus sensibles sont marques comme necessitant validation metier.

## Definition of Done

- Le ticket est implemente selon les conventions Vue 3 + TypeScript strict.
- Les tests pertinents sont ajoutes ou mis a jour.
- L'accessibilite clavier, focus et contraste est verifiee pour les surfaces touchees.
- Le responsive 360 px, tablette et desktop est controle.
- Le build de production passe.
- La documentation ou les contenus concernes sont mis a jour.

## Priorites

- P0: indispensable MVP.
- P1: important pour lancer proprement.
- P2: amelioration post-MVP proche.
- P3: confort, optimisation ou evolution.
